# PhotoHaven releases

Public install packages for **PhotoHaven Haven Server**.

This repository holds **binaries, checksums, and release notes only**. It does not contain PhotoHaven source code.

## Downloads

See [Releases](https://github.com/danschroeder/photohaven-releases/releases) for the latest builds.

## Platforms (planned)

- macOS (first)
- Windows
- Linux / NAS (Docker image and/or native where available)

## Updates

Haven Server checks this repo for new versions. Owners can opt in or out of automatic updates; Admin always has a manual Update action. Rollback is by re-downloading the previous release.

## Source

Product source lives in a private repository. Issues and support: use the PhotoHaven product channels, not this repo (Issues are disabled here).
